# TrainEveryDay

Готовая статическая сборка сайта из TrainEveryDay-Beget.zip. Исходный проект Next.js (package.json, компоненты и конфигурация сборки) в архив не включён. Node.js и база данных для размещения этой сборки не нужны.

## Развёртывание на Beget

1. Создайте сайт в панели Beget и привяжите traineveryday.ru к его каталогу.
2. Сохраните резервную копию существующего public_html.
3. Загрузите содержимое репозитория в public_html: index.html должен лежать непосредственно в public_html, рядом с _next, fonts и .htaccess. README.md и .git на хостинг копировать не нужно.
4. Проверьте сайт по техническому адресу, затем направьте DNS домена на адрес хостинга из панели Beget и подключите SSL Let's Encrypt.
5. Проверьте главную страницу, мобильную версию, ссылки и ответ 404 для несуществующего адреса.

Автоматическое обновление из GitHub пока не настроено. Следующий этап — настроить доставку ветки main на Beget через SSH, храня ключ доступа в GitHub Actions Secrets.

Сохраняйте все файлы _next и __next*.txt: это части статического экспорта Next.js. Для изменения дизайна с пересборкой потребуется исходный проект.
